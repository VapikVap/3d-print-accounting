# Изменения

## 0.0.3 — безопасность в локальной сети

- Привязка к сертификату принтера Bambu: запоминается при первом входе, сверяется до отправки кода
  доступа (MQTT и FTPS). Подменённому устройству код не уходит; тревога в журнале и на «Обзоре»,
  кнопка «Доверять заново» (после обновления прошивки или замены принтера).
- Автопоиск не меняет IP принтера по объявлению, если на новом адресе другой сертификат.
- Не больше 3 автоматически добавленных принтеров за 10 минут (защита от потока подделок).
- Коды доступа, ключи Tuya и токен Яндекса хранятся зашифрованными (Windows DPAPI); уже сохранённые
  шифруются при первом запуске (перед этим — резервная копия базы).
- Ограничения размера файлов с принтера и распаковки.
- API-ключ Moonraker для принтеров Klipper с включённой авторизацией.
- Памятка «Безопасность сети» в «Устройствах» и SECURITY.md (как сообщить об уязвимости).

## 0.0.2

- Все слайсеры, а не только Bambu Studio: приложение само находит установленные Bambu Studio,
  OrcaSlicer, Creality Print, ElegooSlicer, Anycubic Slicer Next, QIDI Studio, Snapmaker Orca,
  PrusaSlicer, SuperSlicer, UltiMaker Cura, FlashPrint, ideaMaker, Simplify3D; любой другой можно
  добавить вручную (.exe). Вкладка «Bambu Studio» стала вкладкой «Слайсеры».
- Профили пластика для новых катушек — из всех найденных слайсеров: формат Orca/Bambu
  (Bambu Studio, OrcaSlicer, Creality Print и другие форки), PrusaSlicer (INI) и Cura (материалы XML,
  цена катушки из настроек Cura). Копии одного пластика под разные принтеры склеиваются.
- Выбор слайсера, который открывает файлы заданий; в списке файлов — «Открыть в…» любом слайсере.
- Недавние папки проектов из всех слайсеров как подсказка для папки нарезки.
- Установщик `install.bat`: сам скачивает приложение с GitHub, при необходимости ставит Python 3.12
  и WebView2, библиотеки, ярлыки и запускает. Повторный запуск — обновление без потери данных.
- `start.bat` теперь делает то же, что `install.bat`.

Проверено на этом ПК с Bambu Studio 2.08 и Creality Print 7.3; остальные слайсеры — по формату их файлов.

## 0.0.1 — первая публичная версия

- Окно приложения для Windows со значком в трее, запуск по ярлыку, автозапуск с Windows (по желанию).
- Bambu Lab: автопоиск в сети, MQTT по TLS, файл задания с принтера по FTPS, план расхода по пластинам.
- Многоцветная печать: пластики детали, привязка катушек к слотам AMS, расход и стоимость по каждой катушке.
- Определение системы подачи: AMS, AMS 2 Pro, AMS HT, AMS lite; влажность, температура, сушка.
- Klipper/Moonraker (Creality K1 Max): расход с принтера, история заданий.
- Розетки: Shelly Gen1/Gen2, Tasmota, Tuya (локально), Яндекс Умный дом.
- Себестоимость: пластик, электричество, амортизация, работа; наценка; выгрузка в Excel.
- Связь с Bambu Studio: профили филамента, открытие файлов, папка нарезки.
- Темы оформления, эмуляторы P1S и Moonraker, демо-режим, 76 автотестов.

Проверено на эмуляторах; на реальном оборудовании ещё не проверялось.
