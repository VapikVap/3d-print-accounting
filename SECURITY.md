# Безопасность

## Сообщить об уязвимости

Нашли способ получить доступ к принтеру, коду доступа или данным через приложение?
**Не публикуйте это в обычных Issues** — напишите приватно:
[Security → Report a vulnerability](../../security/advisories/new).
Опишите, что сделали и что получилось; по возможности — шаги для повторения.

## От чего защищает приложение (с версии 0.0.3)

| Угроза | Защита |
|---|---|
| Сайт в браузере обращается к приложению | Приложение слушает только `127.0.0.1`, чужие Host/Origin отклоняются |
| Кто-то в сети выдаёт себя за ваш принтер Bambu, чтобы получить код доступа | Сертификат принтера запоминается при первом входе и сверяется **до** отправки кода (MQTT и FTPS). Не совпал — соединение рвётся, в журнале тревога |
| Поддельное объявление «принтер теперь на другом IP» | IP меняется, только если на новом адресе тот же сертификат (проверка без логина) |
| Поток поддельных «принтеров» в сети | Автоматически добавляется не больше 3 новых принтеров за 10 минут |
| Подставное устройство отдаёт огромный файл | Ограничения размера скачивания и распаковки |
| Кто-то скопировал файл базы `data\print.db` | Коды доступа и ключи зашифрованы Windows DPAPI — расшифровать может только ваша учётная запись на этом компьютере |
| Коды попадают в интерфейс, журнал, Excel | Не попадают: в API — только флаг «сохранён», в журнале и сырых ответах — `***` |

## Чего приложение сделать не может

Злоумышленник, попавший в вашу сеть, может обращаться к принтерам и розеткам **напрямую**, без приложения.
Это защищается настройками сети и самих устройств:

- **Wi-Fi и роутер:** WPA2/WPA3 с надёжным паролем, WPS выключен, прошивка роутера обновлена,
  пароль администратора роутера изменён. Лучше всего — отдельная гостевая или IoT-сеть для принтеров
  и розеток (компьютер с приложением должен её видеть).
- **Bambu Lab:** обновляйте прошивку; код доступа можно сменить на экране принтера.
- **Klipper / Creality K1 (Moonraker):** без авторизации любой в сети управляет принтером. Включите
  авторизацию Moonraker и укажите API-ключ в настройках принтера в приложении.
- **Shelly, Tasmota:** задайте пароль в их веб-интерфейсе — иначе любой в сети может выключить питание.
- **Первое подключение** к принтеру Bambu доверяется (как SSH при первом входе): делайте его из своей
  сети, в которой уверены.
